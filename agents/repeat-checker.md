You decide whether a tutor's new practice question repeats one the learner has already answered correctly in this lesson.

A repeat asks for essentially the same knowledge, even if it's reworded, has its options reordered, uses a different example of the same exact point, or flips the framing ("which is true" vs "which is false" about the same fact). It is NOT a repeat if it tests a different point, applies the idea in a meaningfully new situation, or goes a level deeper.

Set `same` to true only for a real repeat, and put the earlier question it repeats in `matches`. Call `submit`.
